# ZoneTilerWM Keyboard Shortcuts

## Global Shortcuts

| Shortcut | Description |
|---|---|
| `HYPER` + `-` | Show window hints |
| `HYPER` + `=` | Toggle Activity Monitor |
| `Ctrl`+`Cmd` + `9` | Enable Pomodoro timer |
| `Ctrl`+`Cmd` + `0` | Disable Pomodoro timer |
| `Shift`+`Ctrl`+`Cmd` + `0` | Reset Pomodoro work timer |
| `Shift`+`Ctrl`+`Cmd` + `R` | Reload ZoneTilerWM configuration |

## Tiling Shortcuts

| Shortcut | Description |
|---|---|
| `Ctrl`+`Cmd` + `zone_key` | Move window to a specific zone |
| `Shift`+`Ctrl`+`Cmd` + `zone_key` | Focus a window in a specific zone |
| `Ctrl`+`Cmd` + `p` | Move window to the next monitor |
| `Ctrl`+`Cmd` + `;` | Move window to the previous monitor |
| `HYPER` + `\` | Toggle Zen mode (maximize window) |
| `HYPER` + `Enter` | **Auto-Tile All Windows** (Ripple & Compact) |
| `HYPER` + `R` | Toggle Resize Mode (Adjust grid lines) |

## Application Shortcuts

| Shortcut | Description |
|---|---|
| `Shift`+`Ctrl` + `key` | Toggle application (defined in `config.toml`) |
| `HYPER` + `key` | Toggle application (defined in `config.toml`) |
| `Shift`+`Ctrl` + `;` | Show application shortcuts |

## Window Memory Shortcuts

| Shortcut | Description |
|---|---|
| `HYPER` + `9` | Capture and save all window positions |
| `HYPER` + `0` | Restore all saved window positions |

## Audio Switcher

| Shortcut | Description |
|---|---|
| `HYPER` + `'` | Cycle through audio output devices |

---
*`HYPER` is defined as `Shift`+`Ctrl`+`Alt`+`Cmd`*
*`zone_key` refers to the keys defined in the `layouts` section of your `config.toml` (e.g., y, u, h, j, k, etc.).*
